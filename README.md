# Playwright Salesforce UI Automation Starter (TypeScript)

A minimal Playwright + TypeScript test automation starter kit for UI testing of Salesforce and modern web apps.

## Features
- Playwright test runner with TypeScript
- Cross-browser testing (Chromium, Firefox)
- Small example test included
- Ready for CI/CD integration

## Project structure
tests/
└── sample.spec.ts
playwright.config.ts
tsconfig.json


## Install 

npm install
npx playwright install

## Run tests
npm test
 or
npx playwright test
